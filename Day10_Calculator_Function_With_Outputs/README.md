# **_Day 10 – Calculator 🧮_**

## 📌 Project Overview

This is a command-line calculator built using Python.
It performs basic arithmetic operations and also supports modulus (%) and power (**).
Users can continue calculations using the previous result or start a new calculation.



## The main goals of this project:
1. Learn to write functions for each operation 
2. Use a dictionary to map operators to functions 
3. Practice nested loops for control flow 
4. Handle invalid inputs and errors safely 
5. Understand break, continue, and return in loops

## Features

1. Supports addition, subtraction, multiplication, division, modulus, and power 
2. Uses a dictionary-based function mapping instead of if-elif chains 
3. Allows chaining calculations with previous results 
4. Handles division by zero safely 
5. Graceful handling of invalid operators 
6. ASCII art logo for better UI

## 🧠 Concepts Learned

- Functions as first-class objects 
- Dictionary-based function dispatch 
- Nested while loops 
- Difference between continue, break, and return 
- Safe error handling (None return for invalid operations)
- Input validation and user-friendly error messages
