# Day 9 – Silent Auction 🏆

## 📌 Project Overview

* Python dictionaries
* Loops (`while` and `for`)
* Conditional logic
* User input handling

We build a **Silent Auction** program where multiple users can place bids, and the program determines the 
highest bidder.

## How the Program Works

1. Display an auction logo.
2. Ask the user for their name and bid amount.
3. Store the data in a dictionary.
4. Ask if there are more bidders.
5. Repeat until no more bidders are left.
6. Loop through all bids to find the highest bid.
7. Display the winner and the winning amount.
